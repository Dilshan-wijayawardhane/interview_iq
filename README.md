# 🎯 InterviewIQ – AI Interview Preparation Platform

InterviewIQ is an AI-powered full-stack web application designed to help users prepare for job interviews through mock interviews, coding challenges, resume analysis, and intelligent feedback.

It simulates real interview scenarios using AI to improve technical knowledge, communication skills, and confidence.

---

## 🚀 Features

### 🧠 AI Mock Interviews
- Role-based interview generation (Frontend, Backend, Full Stack, etc.)
- Technical, HR, and Behavioral interview modes
- Dynamic AI-generated follow-up questions
- Real-time feedback and scoring

### 💻 Coding Interview Practice
- Built-in code editor (Monaco Editor)
- Multiple programming language support
- Code execution via Judge0 API
- AI hints and suggestions
- Timer-based challenges

### 📄 Resume Analyzer
- Upload resume (PDF/DOCX)
- ATS score evaluation
- Skill gap detection
- AI improvement suggestions

### 📊 Performance Dashboard
- Interview history tracking
- Skill progress analytics
- Score visualization charts
- Weak area identification

### 🔐 Authentication System
- Firebase Authentication
- Google Sign-In
- Protected routes
- User profile management
